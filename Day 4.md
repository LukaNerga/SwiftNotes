# 100 Days of SwiftUI

# Day 4 — Type Annotations

## Type Annotations

Swift can usually infer data types automatically, but you can also specify them manually using type annotations.

---

## Strings

```swift
let name: String = "Luka"
```

`String` stores text values.

---

## Integers

```swift
var age: Int = 0
```

`Int` stores whole numbers.

---

## Arrays

```swift
var soda: [String] = ["Coke", "Pepsi"]
```

This creates an array containing strings.

---

## Empty Arrays

```swift
var soda = [String]()
```

or

```swift
var soda: [String] = []
```

Both create an empty string array.

---

## Why Use Type Annotations?

Type annotations:
- make code easier to read
- help avoid mistakes
- are useful for empty collections
- improve code clarity
